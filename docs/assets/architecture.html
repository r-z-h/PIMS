工程企业项目成本管理系统 · 体系结构图

单机单用户 · 本地 Web 应用 · 一套数据两处入口 · 收付流水不参与利润

使用者一人一机，不做协同与权限
老板（唯一使用者）
一个密码进入系统；首次登录强制设 3 个密保问题
使用方式
双击 start.bat → 浏览器自动打开 127.0.0.1:8000
前端层 · 展示与交互Vite + React 18 + TypeScript + Ant Design
页面（9 个菜单）
首页（项目盈亏总表）· 项目档案 / 项目详情 · 记账（五类成本录入）· 收/付款（资金流水）· 成本（按构成汇总，也可录入）· 往来（应收 / 应付）· 库存 · 结算（人工）· 设置
公共组件
金额输入 / 金额展示（整数分运算，无浮点漂移）· 字典下拉（可现场新增、对方可直接输入）· 变更记录时间线 · 冲销弹窗 · 登记已付弹窗
状态与缓存
Zustand：登录态 / 当前项目 / 时间段 / 字典缓存
接口调用
axios 统一封装：{code,message,data} 信封 · 401 收敛跳登录 · 会话失效闩锁
后端层 · 业务规则唯一实现处Python + FastAPI + SQLAlchemy
接入与安全
登录 / 会话 Cookie · 密保问题 · 统一响应信封与错误码 · 变更日志（谁在什么时候改了什么）
业务服务（规则只在这里实现一次）
项目与盈亏计算 · 五类成本（人工 / 材料 / 机械 / 杂费 / 垫付）· 材料采购联动库存 · 成本 ↔ 应付单联动 · 资金收付 · 应收应付与冲销 · 人工结算 · 汇总与 Excel 导出
静态托管
同时把前端页面发给浏览器，所以只有一个启动入口，不需要单独起前端服务
数据层 · 单文件数据库SQLite（backend/data/pims.db，拷走即搬迁）
主数据
项目档案（甲方预算 / 我方成本预算）· 字典项（杂费小类 / 材料 / 单位 / 对方）
成本（一份数据两个入口）
成本主表 + 人工工天 / 材料采购 / 机械台班 / 垫付明细
资金与往来
资金收付流水 · 应收应付单 · 冲销记录 · 人工结算单
库存与留痕
库存余量（按项目隔离）· 库存流水（入库 / 领用）· 变更日志 · 启动自动备份（留 7 份）
核心机制：录一笔账，系统同时做三件事
① 录成本在「记账」或「成本」页录一笔（人工 / 材料 / 机械 / 杂费 / 垫付）
→
② 自动生成应付单同一时刻生成「我欠谁多少」，金额＝成本全额，并关联该笔成本
→
③ 顺手登记已付弹窗填已付金额（选填）→ 生成付款流水并自动冲销该应付单
→
结果应付单状态：未收付 → 部分 → 已结清；付款流水在「收/付款」页可见
不得擅改的口径（代码与文档必须一致）
实际成本＝ 人工 + 材料 + 机械 + 杂费 + 垫付（五类之和）
预计利润＝ 甲方预算 − 我方成本预算
结算利润＝ 甲方预算 − 实际成本
资金收付与应收应付一律不参与利润计算；系统不提供「现金结余」
材料：采购即成本并同时入库；领用只减库存、不再扣一次成本
人工：按工天实时入成本；项目结束的结算只做汇总与发放，不重复计入
成本改金额 → 应付单实时同步；已冲销则拒绝改，需先撤销冲销
删除成本 → 应付单保留，只提示不自动删
