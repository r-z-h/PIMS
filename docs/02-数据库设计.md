# 02 — 数据库设计

> 数据库：**SQLite**（文件 `backend/data/pims.db`）
> 约定：[`01-开发手册.md`](01-开发手册.md) 第 1.3 节（金额 `NUMERIC(14,2)` + `Decimal`；业务日期用 `TEXT 'YYYY-MM-DD'`；时间戳 `DATETIME`）
> 命名：表名、字段名一律 `snake_case`；所有业务表带 `deleted`（软删除）、`created_at`、`updated_at`

---

## 1. 表清单

| # | 表名 | 中文名 | 说明 |
|---|---|---|---|
| 1 | `sys_setting` | 系统设置 | 键值对：密码散列、密保、会话 token、初始化标记 |
| 2 | `password_reset_log` | 改密记录 | 改密 / 重置留痕 |
| 3 | `project` | 项目档案 | 含甲方预算、我方成本预算、成员名单 |
| 4 | `cost` | 成本主表 | 五类成本统一存放，`type` 区分 |
| 5 | `labor_work` | 工天明细 | 人工成本的构成明细（1:1 对应 `cost`） |
| 6 | `material_item` | 材料采购明细 | 材料成本的数量/单价/供应商（1:1 对应 `cost`） |
| 7 | `machine_item` | 机械明细 | 台班/小时与单价（1:1 对应 `cost`） |
| 8 | `advance_item` | 垫付明细 | 垫付人与事由（1:1 对应 `cost`） |
| 9 | `funds_flow` | 资金流水 | 收/付流水账，**不影响利润** |
| 10 | `ar_ap` | 应收应付单 | `type` 区分应收/应付 |
| 11 | `ar_ap_offset` | 冲销记录 | 收付款与单据的核销关系 |
| 12 | `inventory` | 库存余量 | 按「项目+材料+单位」聚合 |
| 13 | `inventory_txn` | 库存流水 | 入库 / 领用 |
| 14 | `labor_settle` | 人工结算单 | 按人汇总应付，**不重复入成本** |
| 15 | `dict_item` | 数据字典 | 杂费小类、材料、单位、对方 |
| 16 | `change_log` | 变更日志 | 所有增删改的前后快照 |

**枚举值一览**（写库时用英文，前端显示中文）

| 字段 | 取值 |
|---|---|
| `cost.type` | `labor` 人工 / `material` 材料 / `machine` 机械 / `misc` 杂费 / `advance` 垫付 |
| `funds_flow.direction` | `in` 收 / `out` 付 |
| `funds_flow.biz_type` | `progress` 进度款 / `settle` 结算款 / `advance` 预支 / `material` 材料款 / `labor` 人工费 / `machine` 机械费 / `misc` 杂费 / `advance_pay` 垫付 / `other` 其他 |
| `funds_flow.pay_method` | `cash` 现金 / `wechat` 微信 / `bank_card` 银行卡 / `transfer` 转账 |
| `ar_ap.type` | `receivable` 应收 / `payable` 应付 |
| `ar_ap.biz_type` | 应收：`progress` / `settle`；应付：同 `funds_flow.biz_type` |
| `ar_ap.status` | `open` 未收付 / `partial` 部分 / `closed` 已结清 |
| `inventory_txn.txn_type` | `in` 入库 / `out` 领用 |
| `machine_item.measure` | `shift` 台班 / `hour` 小时 |
| `project.status` | `ongoing` 在建 / `finished` 完工 |
| `change_log.action` | `create` / `update` / `delete` |
| `dict_item.dict_type` | `misc_category` / `material` / `unit` / `partner` |
| `labor_settle.status` | `unpaid` 未发 / `partial` 部分 / `paid` 已发 |

## 2. 表结构明细

### 2.1 `sys_setting` 系统设置

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `key` | TEXT | PK | 键 |
| `value` | TEXT | | 值 |
| `updated_at` | DATETIME | | |

预置键：

| key | 说明 |
|---|---|
| `password_hash` | `pbkdf2_sha256$迭代次数$盐$散列`，初始为 `123456` 的散列 |
| `pwd_initialized` | `0` 表示仍是初始密码，登录后强制引导 |
| `sec_q1` / `sec_a1` | 密保问题 1 与答案散列 |
| `sec_q2` / `sec_a2` | 密保问题 2 与答案散列 |
| `sec_q3` / `sec_a3` | 密保问题 3 与答案散列 |
| `security_ready` | 3 组密保是否已设置（`0/1`） |
| `session_token` | 当前有效会话 token（单用户，登录覆盖） |
| `session_expire_at` | 会话过期时间 |

### 2.2 `password_reset_log` 改密记录

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | |
| `action` | TEXT | NOT NULL | `change` 正常改密 / `reset_by_security` 密保重置 / `reinit` 删库重来 |
| `result` | TEXT | NOT NULL | `success` / `fail` |
| `detail` | TEXT | | 失败原因等 |
| `created_at` | DATETIME | NOT NULL | |

### 2.3 `project` 项目档案

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | |

| `client_name` | TEXT | | 甲方 / 业主 |
| `location` | TEXT | | 地点 |
| `manager` | TEXT | | 负责人 |
| `start_date` | TEXT | | 开工日期 |
| `status` | TEXT | NOT NULL DEFAULT `ongoing` | `ongoing` / `finished` |
| `client_budget` | NUMERIC(14,2) | NOT NULL DEFAULT 0 | 甲方预算（合同额） |
| `cost_budget` | NUMERIC(14,2) | NOT NULL DEFAULT 0 | 我方成本预算 |
| `members` | TEXT | | 项目成员名单（JSON 数组：`["张三","李四"]`，或逗号分隔文本） |
| `remark` | TEXT | | 备注 |
| `deleted` | INTEGER | NOT NULL DEFAULT 0 | |
| `created_at` / `updated_at` | DATETIME | | |

索引：`idx_project_deleted(deleted)`、`idx_project_status(status)`

### 2.4 `cost` 成本主表（五类统一）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | |
| `project_id` | INTEGER | NOT NULL, FK → project(id) | |
| `type` | TEXT | NOT NULL | `labor` / `material` / `machine` / `misc` / `advance` |
| `category` | TEXT | | **仅杂费使用**：杂费小类（取字典 `misc_category`） |
| `amount` | NUMERIC(14,2) | NOT NULL | 金额（人工可手改，其余自动算） |
| `biz_date` | TEXT | NOT NULL | **成本发生日期**（时间段筛选依据） |
| `partner` | TEXT | | 对方：供应商 / 出租方 / 垫付人 |
| `remark` | TEXT | | 备注（部位、工序等自由文字写这里） |
| `deleted` | INTEGER | NOT NULL DEFAULT 0 | |
| `created_at` / `updated_at` | DATETIME | | |

索引：`idx_cost_project(project_id, biz_date)`、`idx_cost_type(type)`、`idx_cost_deleted(deleted)`

### 2.5 `labor_work` 工天明细（1:1 关联 `cost`）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | |
| `cost_id` | INTEGER | NOT NULL UNIQUE, FK → cost(id) | 一对一 |
| `worker_name` | TEXT | NOT NULL | 姓名（手输，无档案） |
| `work_days` | NUMERIC(8,2) | NOT NULL | 工日数 |
| `day_rate` | NUMERIC(14,2) | NOT NULL | 日工价 |
| `remark` | TEXT | | |

索引：`idx_labor_worker(worker_name)`

> 口径：录工天即写 `cost`（`amount = work_days × day_rate`，允许手改），因此**人工成本实时入账**。

### 2.7 `machine_item` 机械明细（1:1 关联 `cost`）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|

| `quantity` | NUMERIC(12,2) | NOT NULL | 台班数或小时数 |
| `unit_price` | NUMERIC(14,2) | NOT NULL | 单价 |

### 2.8 `advance_item` 垫付明细（1:1 关联 `cost`）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | |
| `cost_id` | INTEGER | NOT NULL UNIQUE, FK → cost(id) | |
| `payer` | TEXT | | 垫付人（默认「老板」） |
| `purpose` | TEXT | | 垫付事由 |

> **杂费小类**：不单独建明细表，直接存在 `cost.category` 字段（仅 `type='misc'` 时使用），
> 其余四类的 `category` 为空。这样杂费也能按小类分组统计。

### 2.10 `ar_ap` 应收应付单

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | |
| `project_id` | INTEGER | NOT NULL, FK → project(id) | |
| `type` | TEXT | NOT NULL | `receivable` 应收 / `payable` 应付 |
| `biz_type` | TEXT | NOT NULL | 进度款 / 结算款 / 材料款 / 人工费 … |
| `amount` | NUMERIC(14,2) | NOT NULL | 单据金额 |
| `settled_amount` | NUMERIC(14,2) | NOT NULL DEFAULT 0 | 已冲销金额 |
| `status` | TEXT | NOT NULL DEFAULT `open` | `open` / `partial` / `closed` |
| `biz_date` | TEXT | NOT NULL | 单据日期 |
| `partner` | TEXT | | 对方（甲方 / 供应商 / 工人） |
| `cost_id` | INTEGER | FK → cost(id) | 可选：应付单可关联产生它的成本 |

## 3. 完整建表 DDL

> 存为 `backend/app/db/schema.sql`，启动时执行（`CREATE TABLE IF NOT EXISTS`）。

```sql
PRAGMA foreign_keys = ON;
PRAGMA journal_mode = WAL;

-- 1. 系统设置
CREATE TABLE IF NOT EXISTS sys_setting (
  key        TEXT PRIMARY KEY,
  value      TEXT,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 2. 改密记录
CREATE TABLE IF NOT EXISTS password_reset_log (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  action     TEXT NOT NULL,
  result     TEXT NOT NULL,
  detail     TEXT,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 3. 项目档案
CREATE TABLE IF NOT EXISTS project (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  name          TEXT NOT NULL,
  client_name   TEXT,
  location      TEXT,
  manager       TEXT,
  start_date    TEXT,
  status        TEXT NOT NULL DEFAULT 'ongoing' CHECK (status IN ('ongoing','finished')),
  client_budget NUMERIC(14,2) NOT NULL DEFAULT 0,
  cost_budget   NUMERIC(14,2) NOT NULL DEFAULT 0,
  members       TEXT,
  remark        TEXT,
  deleted       INTEGER NOT NULL DEFAULT 0,
  created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_project_deleted ON project(deleted);
CREATE INDEX IF NOT EXISTS idx_project_status  ON project(status);

-- 4. 成本主表（五类）
CREATE TABLE IF NOT EXISTS cost (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  project_id INTEGER NOT NULL REFERENCES project(id),
  type       TEXT NOT NULL CHECK (type IN ('labor','material','machine','misc','advance')),
  category   TEXT,                       -- 仅杂费使用：杂费小类
  amount     NUMERIC(14,2) NOT NULL,
  biz_date   TEXT NOT NULL,
  partner    TEXT,
  remark     TEXT,
  deleted    INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_cost_project ON cost(project_id, biz_date);
CREATE INDEX IF NOT EXISTS idx_cost_type    ON cost(type);
CREATE INDEX IF NOT EXISTS idx_cost_deleted ON cost(deleted);

-- 5. 工天明细
CREATE TABLE IF NOT EXISTS labor_work (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  cost_id     INTEGER NOT NULL UNIQUE REFERENCES cost(id),
  worker_name TEXT NOT NULL,
  work_days   NUMERIC(8,2) NOT NULL,
  day_rate    NUMERIC(14,2) NOT NULL,
  remark      TEXT
);
CREATE INDEX IF NOT EXISTS idx_labor_worker ON labor_work(worker_name);

-- 6. 材料采购明细
CREATE TABLE IF NOT EXISTS material_item (
  id                INTEGER PRIMARY KEY AUTOINCREMENT,
  cost_id           INTEGER NOT NULL UNIQUE REFERENCES cost(id),
  material_name     TEXT NOT NULL,
  unit              TEXT NOT NULL,
  quantity          NUMERIC(12,3) NOT NULL,
  unit_price        NUMERIC(14,2) NOT NULL,
  supplier          TEXT,
  inventory_txn_id  INTEGER REFERENCES inventory_txn(id)
);

-- 7. 机械明细
CREATE TABLE IF NOT EXISTS machine_item (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  cost_id      INTEGER NOT NULL UNIQUE REFERENCES cost(id),
  machine_name TEXT NOT NULL,
  measure      TEXT NOT NULL CHECK (measure IN ('shift','hour')),
  quantity     NUMERIC(12,2) NOT NULL,
  unit_price   NUMERIC(14,2) NOT NULL,
  lessor       TEXT
);

-- 8. 垫付明细
CREATE TABLE IF NOT EXISTS advance_item (
  id       INTEGER PRIMARY KEY AUTOINCREMENT,
  cost_id  INTEGER NOT NULL UNIQUE REFERENCES cost(id),
  payer    TEXT,
  purpose  TEXT
);

-- 9. 资金流水
CREATE TABLE IF NOT EXISTS funds_flow (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  project_id INTEGER NOT NULL REFERENCES project(id),
  direction  TEXT NOT NULL CHECK (direction IN ('in','out')),
  biz_type   TEXT NOT NULL CHECK (biz_type IN
               ('progress','settle','advance','material','labor','machine','misc','advance_pay','other')),
  amount     NUMERIC(14,2) NOT NULL,
  biz_date   TEXT NOT NULL,
  partner    TEXT,
  pay_method TEXT CHECK (pay_method IN ('cash','wechat','bank_card','transfer')),
  remark     TEXT,
  deleted    INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_funds_project ON funds_flow(project_id, biz_date);
CREATE INDEX IF NOT EXISTS idx_funds_dir     ON funds_flow(direction);

-- 10. 应收应付单
CREATE TABLE IF NOT EXISTS ar_ap (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  project_id     INTEGER NOT NULL REFERENCES project(id),
  type           TEXT NOT NULL CHECK (type IN ('receivable','payable')),
  biz_type       TEXT NOT NULL,
  amount         NUMERIC(14,2) NOT NULL,
  settled_amount NUMERIC(14,2) NOT NULL DEFAULT 0,
  status         TEXT NOT NULL DEFAULT 'open' CHECK (status IN ('open','partial','closed')),
  biz_date       TEXT NOT NULL,
  partner        TEXT,
  cost_id        INTEGER REFERENCES cost(id),
  remark         TEXT,
  deleted        INTEGER NOT NULL DEFAULT 0,
  created_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

## 4. 核心查询 SQL

### 4.1 项目盈亏总表（首页主查询）

```sql
SELECT
  p.id,
  p.name,
  p.status,
  p.client_budget,
  p.cost_budget,
  p.client_budget - p.cost_budget                             AS expect_profit,   -- 预计利润
  IFNULL(c.actual_cost, 0)                                    AS actual_cost,     -- 实际成本
  p.client_budget - IFNULL(c.actual_cost, 0)                  AS settle_profit,   -- 结算利润
  p.cost_budget  - IFNULL(c.actual_cost, 0)                   AS budget_left      -- 成本预算余额
FROM project p
LEFT JOIN (
  SELECT project_id, SUM(amount) AS actual_cost
  FROM cost
  WHERE deleted = 0
    AND (:start_date IS NULL OR biz_date >= :start_date)
    AND (:end_date   IS NULL OR biz_date <= :end_date)
  GROUP BY project_id
) c ON c.project_id = p.id
WHERE p.deleted = 0
ORDER BY p.status, p.id DESC;
```

### 4.2 五类成本构成（项目详情）

```sql
SELECT type, SUM(amount) AS amount, COUNT(*) AS cnt
FROM cost
WHERE deleted = 0 AND project_id = :project_id
  AND (:start_date IS NULL OR biz_date >= :start_date)
  AND (:end_date   IS NULL OR biz_date <= :end_date)
GROUP BY type;
```

### 4.3 库存余量（按项目隔离）

```sql
SELECT material_name, unit, in_qty, out_qty, in_qty - out_qty AS balance
FROM inventory
WHERE project_id = :project_id
ORDER BY material_name;
```

### 4.4 待冲销单据与未结金额

```sql
SELECT id, type, biz_type, biz_date, partner, amount, settled_amount,
       amount - settled_amount AS unsettled, status
FROM ar_ap
WHERE deleted = 0
  AND project_id = :project_id
  AND type = :type            -- receivable / payable
  AND status <> 'closed'
ORDER BY biz_date, id;
```

### 4.5 人工按人汇总（结算预览）

```sql
SELECT w.worker_name,
       SUM(w.work_days)  AS total_days,
       SUM(c.amount)     AS amount_due        -- 与已入成本一致，不重复计
FROM labor_work w
JOIN cost c ON c.id = w.cost_id
WHERE c.deleted = 0 AND c.project_id = :project_id
GROUP BY w.worker_name
ORDER BY amount_due DESC;
```

### 4.6 该收未收 / 该付未付

```sql
SELECT type, SUM(amount - settled_amount) AS unsettled
FROM ar_ap
WHERE deleted = 0 AND status <> 'closed'
GROUP BY type;
```

## 6. 迁移与备份

- **迁移**：第一版不引入 Alembic；`schema.sql` 用 `CREATE TABLE IF NOT EXISTS`，字段变更时写一个 `db/migrations/NNN_xxx.sql` 并在启动时按 `sys_setting.schema_version` 顺序执行。
- **实现说明**：`app/db` 是一个**包**（`app/db/__init__.py` 承载 engine / SessionLocal / get_db / PRAGMA / init_db），
  因为 `app/db.py` 无法与 `app/db/schema.sql` 同目录共存；对外仍是 `from app.db import get_db`。
- **字典预置**：首次启动**幂等**写入预置字典（杂费小类 6 条、单位 10 条、材料 8 条）；
  两个示例项目才需要 `python -m app.seed`（默认不写）。
- **备份**：设置页提供「导出数据库文件」按钮（直接复制 `pims.db`）；启动时自动备份到 `backend/data/backup/pims-YYYYMMDD.db`，保留最近 7 份（`PIMS_AUTO_BACKUP=0` 可关闭）。
- **重置**：`POST /api/system/reset`（`{"confirm":"RESET"}`）**清空业务表与变更日志，保留密码、密保与字典**，执行前自动备份。
  若要彻底回到初始状态（密码恢复为 `123456`），删除 `backend/data/pims.db` 后重启。
